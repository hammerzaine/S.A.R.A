What is Space Engineers?

Space Engineers is a voxel-based sandbox game by Keen Software House. You mine, weld, grind, and build ships, stations, and rovers out of interlocking blocks. The fun really kicks off when you automate it.

The Programming Block

The Programmable Block (PB) is an in-game computer. Drop one on your grid, paste in a script, hit Recompile, and it runs your C# code against everything on the grid. It can read sensors, flick thrusters, sort cargo, talk to other grids over antennas — the lot. It's the brain of any serious base.

The Language: C#

The PB runs a whitelisted subset of C# (.NET). You do NOT get the whole framework — dangerous bits like System.Threading.Thread are blocked. Three hard limits:

  • 100,000 characters max script size.
  • 50,000 instruction counter per run (method calls, loops, branches all count).
  • Whitelist of allowed .NET types — anything else is a compile error.

Every script has this skeleton:

public Program() { }            // runs once on (re)compile
public void Save() { }          // called on game save / before recompile
public void Main(string argument) { /* your logic */ }

The class is always named Program and inherits MyGridProgram. Your entry point is Main. The argument string comes from timer/button/sensor toolbars.
